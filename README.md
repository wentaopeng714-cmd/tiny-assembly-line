# Tiny Assembly Line

A standalone automation/factory incremental with four linked production stages, orders, offline progress, and autosave. Open `index.html` directly.

Based on concepts from [Aldo111/incremental-game-engine-js](https://github.com/Aldo111/incremental-game-engine-js) by Adarsh Sinha. MIT License; the original license is preserved in `LICENSE`. This edition supplies a new production chain, balance, interface, palette, copy, and audio.
